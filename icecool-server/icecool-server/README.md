# IceCool Server

Backend server for the IceCool ice cream and dessert delivery platform.

## Features

- RESTful API
- WebSocket (Socket.io) for real-time updates
- MongoDB database
- JWT authentication
- User management
- Shop management
- Product catalog
- Order processing
- Delivery tracking

## Environment Variables

Create a `.env` file with:
- `NODE_ENV` - Development or production
- `PORT` - Server port
- `MONGODB_URI` - MongoDB connection string
- `JWT_SECRET` - Secret for JWT tokens
