# IceCool Client

Frontend for the IceCool ice cream and dessert delivery platform built with React.

## Features

- Responsive design
- User authentication (mobile number + OTP)
- Shop discovery and browsing
- Product customization
- Cart management
- Order placement and tracking
- About us page with company information
- Map integration (OpenStreetMap)

## Pages

- Home (`/`) - Landing page
- About (`/about`) - Company information including CEO details
- Login/Signup - Authentication
- Shop List - Browse available shops
- Shop Detail - View shop information and products
- Product Detail - View and customize products
- Cart - Review and modify cart
- Checkout - Place order
- Order Tracking - View order status
